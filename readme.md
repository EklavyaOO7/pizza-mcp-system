# 🍕 AI-Ready Pizza MCP System

This project demonstrates how to automatically convert OpenAPI specifications into MCP-compatible tools and use AI agents to place and coordinate pizza orders.

## 🚀 Features
- FastAPI backend (Menu, Order, Order Tracking)
- OpenAPI auto-generation
- OpenAPI → MCP tool conversion
- Ollama-powered ordering agent
- Agent-to-Agent coordination
- Mock backend (allowed by challenge)
